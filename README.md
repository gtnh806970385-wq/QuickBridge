# QuickBridge (简易快速搭建)

Surround/bridge placement mod for GT New Horizons.

## Features

- Surround placement in gaps above/below/in-front of blocks
- Visual indicators: 2D HUD crosshair + semi-transparent bounding box
- Smart detection: only triggers when holding blocks and not targeting a block
- Toggle with comma key, fully configurable

## Usage

1. Hold a block (cobblestone, dirt, etc.)
2. Press `,` (comma) to enable
3. Look at a wall/ground and right-click the air next to it
4. Block will be placed bridging from the adjacent solid face
5. Press `,` again to disable

## Requirements

- Minecraft 1.7.10
- Forge 10.13.4.1614+
- GT New Horizons 2.9.0+
